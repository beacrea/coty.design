---
name: Portfolio dossier neutrality
description: Constraints for adding evidence to the portfolio's agent-facing professional dossier.
---

Keep the canonical corpus and every generated agent-facing surface employer-neutral. Do not include target-company framing, role-specific application strategy, or reference-material branding. Detailed evidence belongs in the agent dossier; do not expand the visible homepage unless the user explicitly asks.

**Why:** The user supplied outside material only as an analysis frame and explicitly required that its company-specific context not appear in the portfolio or validation output.

**How to apply:** Check the canonical corpus, Markdown and HTML dossier routes, metadata, preview, and validation labels whenever adding professional evidence. Preserve the public homepage as a separate, concise experience.
